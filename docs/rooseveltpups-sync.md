# Changes made in WiseShift to copy to Roosevelt Pups staff

Fixes and features made in WiseShift (`~/Documents/wiseshift/src/team`) that should also be
made in the Roosevelt Pups staff site (`/home/moecodin/code/rooseveltpups-staff`, `src/team`,
deployed at staff.rooseveltpups.com/team). The other direction (Roosevelt Pups → WiseShift)
is `docs/wiseshift-sync.md` in that repo.

Newest first. When a change is copied over, fill in the last column and note it in that repo's
`docs/wiseshift-sync.md`.

## How to port a change (read this first)

1. In the Roosevelt Pups repo, work on a branch cut from `main`. Never push `main`: Netlify
   publishes it to real staff. Push only when the owner says so. Commit locally only when asked.
2. Copy the WiseShift commit's file changes by hand (the two `src/team` folders have drifted:
   Roosevelt Pups has Tasks, Chat and a calendar link; WiseShift does not). Don't overwrite
   whole files; apply the hunks.
3. **SQL numbers differ.** Roosevelt Pups' updates already run to `027-wiseshift-team.sql`
   (024 Gingr photos, 025 dog ready, 026 calendar link). WiseShift's own numbers do not match:
   renumber each SQL file to the next free number in `supabase/updates` there (028 onward)
   and fix the "Update NNN" / "after NNN" lines and any code comments that name the number.
4. Test against `rooseveltpups-dev` (preview config "rooseveltpups-dev", port 5180, `.env.local`
   holds the dev keys). Run each new SQL file on dev first, then live, BEFORE the site version
   that needs it. Run `npm run build`.
5. Roles/branding there: Manager, Asst. Manager, Daycare Staff; pay rates on; app name
   "Island Schedule". Keep those.
